# Gemini AI Workspace Chatbot

A modern full-stack conversational AI assistant built with Python (Flask) and Google's Gemini Flash model.

## Features
- Modern dark-themed dual-pane workspace UI
- Conversation history tracking in a right-hand sidebar
- Secure API key management with environment variables
- Real-time interaction via Google Gemini API
